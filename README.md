# voxxum

Experimental little voxel sandbox game made in C++ w/ SDL3. Heavily inspired by Minecraft.  
Most of its rendering code is based off of [Base3D](https://github.com/Lukiiy/Base3D).

## Development dependencies

These are most likely downloaded when you try to build with CMakeLists being present.

* [SDL3](https://www.libsdl.org/)
